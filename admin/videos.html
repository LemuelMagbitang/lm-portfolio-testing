Mux Video Library

Manage hosted videos separately from the GitHub-backed editor. Files upload directly from this browser to Mux; a private backend manages records and webhooks.

Backend connection

Use the Supabase URL and public anon/publishable key. Never paste a Mux token, webhook secret, or service-role key into this page.

Only public configuration is stored locally.

Administrator sign in

The backend also checks the account against its administrator allowlist.

Quick guide

Use a Mux video on your website—without IDs

1. Upload a video here, or select an existing upload below. 2. Wait until its status is Ready, then publish it. 3. Choose where to use it:
Homepage hero: set placement to Homepage hero loop; in the main CMS open Hero Loop Animation, choose Only what I add or My additions + latest fill, then save to GitHub.
Project video: in the main CMS open Projects → edit a project → Media (lightbox gallery) → Add media item → Mux video (streamed); select the title and save to GitHub. No IDs need to be pasted into project data.
