Mux Video Library

Manage hosted videos separately from the GitHub-backed editor. Files upload directly from this browser to Mux; a private backend manages records and webhooks.

Backend connection

Use the Supabase URL and public anon/publishable key. Never paste a Mux token, webhook secret, or service-role key into this page.

Only public configuration is stored locally.

Administrator sign in

The backend also checks the account against its administrator allowlist.

Already uploaded in Mux

Import an existing Mux asset
