LM. CMS

Connect your repository

This editor writes directly to your GitHub repo as normal commits — no server, no database.

Need a token? On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token. Scope it to this one repository, and under Permissions give Contents: Read and write — nothing else is needed. The token stays in this browser and talks to GitHub directly; it never passes through any third-party server. Treat it like a password — anyone with it can edit your site.

Full guide: docs.github.com — personal access tokens
